04 / TRUST IS A DESIGN CHOICE

你的助手。
你的数据边界。

本地优先，不是把“云端”藏起来。
数据去哪里，取决于你选择的模型与连接。

01

核心数据留在本机

对话、记忆与提醒保存在本地 SQLite。支持导出、备份与确认后擦除；记忆数据库并非整体加密。

02

使用远端服务，就明确出网

远端模型会收到当前对话与普通记忆；敏感与秘密记忆不进入常规召回。MCP 请求也属于远端访问。

03

感知按需，设备可撤销

Linux 屏幕捕获经系统门户授权，摄像头只取单帧；画面默认不发远端。配对设备可撤销，当前拥有完整所有者权限。

准备一台 Linux 主机

安装 Git、Node.js 24 与 Python 3.10。完整本地语音需要 Ollama、ffmpeg、arecord 等依赖；屏幕捕获还需 python3-gi 与 XDG Desktop Portal。

右侧命令从源码启动。setup 会下载本地模型与组件到用户目录，不使用 sudo；模型下载可能需要时间。doctor 用于检查环境。

3

打开本机 http://127.0.0.1:3081，进入“设置 → 模型”，连接本地模型或你选择的 API 供应商。远端服务可能产生费用。

A FEW GOOD QUESTIONS

开始之前，
你可能想知道。

这个网页就是 Jarvis 吗？+

不是。这是 Jarvis 的产品官网，用于介绍功能与提供上手指引，不运行模型、后端或个人助手。你需要在自己的主机启动 Jarvis，再通过该主机的浏览器地址使用它。

手机和 Windows / Mac 可以用吗？+

可以作为浏览器／PWA 客户端连接主机；手机不能替代后端主机。推荐 Linux 后端，屏幕捕获与摄像头仅限 Linux，本地语音也依赖系统组件。其他平台的基础能力与限制请查看上手文档。

必须使用付费模型吗？+

不必须。可以连接本机 Ollama 模型，也可以选择兼容 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 的供应商。本地模型需要相应硬件资源；远端 API 和服务费用由供应商收取。

它能直接编辑 Office 或自动替我完成业务吗？+

它可以辅助整理文本、起草内容、操作授权范围内的文件，但不承诺完整 Word、Excel、PowerPoint 编辑。WPS 连接尚不可用；当前服务预设是只读的。也不提供长期自主代理、子代理、浏览器自动化或预订付款。

Release 页面能下载一键安装包吗？+

当前 GitHub Release 提供版本说明和源码归档，不提供平台安装器，也不表示已发布到 npm。请按源码安装步骤操作。项目支持自行运行打包命令；具体交付形式请阅读仓库的 distribution 文档。

本地优先，意味着所有内容永不出网吗？+

不意味着。只用本地模型与本地功能时，对话可在本机处理；选择远端模型、远端语音、网络搜索或 MCP 服务时，相关内容会发给对应服务。你可以按需求选择并配置这些能力。
