# 上手：从零到第一次对话

> 这份文档写给“不想碰命令行”的人。需要开发细节时看
> [operations.md](operations.md) 和 [distribution.md](distribution.md)。

Jarvis 是跑在你自己电脑上的助手：数据留在本机，模型由你选的供应商提供。
它不是网页服务，所以**先在一台电脑上启动它**，手机和别的电脑都连这台电脑。

---

## 1. 装在哪台电脑上

| 你的情况 | 建议 |
|---|---|
| 有一台常用的笔记本/台式机 | 装在这台，Windows / macOS / Linux 都行 |
| 想一直在线、手机随时能用 | 装在一台常开的机器（家里的 Linux 小主机、NAS、旧笔记本） |
| 只有手机 | 需要一台电脑做“主机”；手机是客户端 |

**平台能力差异（重要）**

| 功能 | Linux | macOS | Windows |
|---|---|---|---|
| 对话、记忆、提醒、文件、远端模型 | ✅ | ✅ | ✅ |
| 本机模型（Ollama / LM Studio） | ✅ | ✅ | ✅ |
| 屏幕捕获（“看屏幕”） | ✅ | 暂不支持 | 暂不支持 |
| 摄像头单帧 | ✅ | 暂不支持 | 暂不支持 |
| 本地语音识别 / 合成 | ✅（装好依赖） | 可用浏览器录音 + 远端识别 | 同 macOS |
| 开机自启 | ✅ systemd | 手动加登录项 | 手动放启动目录 |

不支持的按钮在界面上会变灰，并把原因写在提示里，不会假装能用。

## 2. 五步启动（Linux 主机）

```bash
cd jarvis
npm install          # 只有一个依赖：ws
npm run app          # 启动服务并打开应用窗口
```

第一次启动要 20 秒左右（建数据库）。窗口没弹出来就手动打开
<http://127.0.0.1:3081/>。

- **没有 Node？** 用便携版：解压后双击 `jarvis`（Windows 是 `Jarvis.cmd`），
  里面自带运行时。见 [distribution.md](distribution.md)。
- **想让它开机就活着**：`bash scripts/install-service.sh`。

---

## 3. 接一个模型（第一次必须做）

打开 **设置 → 模型**，两种选择：

**A. 不花钱：本机模型**

1. 安装 [Ollama](https://ollama.com/download)。
2. 终端执行 `ollama pull qwen2.5:3b`（约 2 GB）。
3. 设置里保持“本地 Ollama”，点“获取模型列表”，选 `qwen2.5:3b`，保存。

**B. 花几块钱：国内供应商（推荐 DeepSeek）**

1. 打开 <http://127.0.0.1:3081/providers>，在“国内直连”里选一个。
2. 点“用这个供应商”→ 回来自动填好地址和模型。
3. 按页面提示去官网创建 API Key，粘贴，点“添加”。
4. 在优先级列表里把它拖到第一位，保存。

> 指南页每个供应商都写了：去哪创建 Key、要填什么地址、大概多少钱、常见坑。
> 额度用完或 Key 失效时，Jarvis 会自动切到优先级里的下一个供应商。

## 4. 装成 App

浏览器打开 Jarvis 后：

- **Chrome / Edge**：地址栏右侧的“安装”图标 → 安装。之后从开始菜单/启动台打开，
  独立窗口，没有地址栏。
- **Safari（macOS）**：文件 → 添加到程序坞。
- **iPhone / iPad**：Safari 打开 → 分享 → 添加到主屏幕。
- **Android**：Chrome → ⋮ → 安装应用。

详细步骤和每台设备的差异在应用里的 **/install** 页面（设置 → 系统 → 安装到这台设备）。

---

## 5. 手机上用

1. 电脑上设置 `JARVIS_HOST=0.0.0.0`，重启 Jarvis。
2. 查电脑的局域网 IP（`ip addr` / `ipconfig`），例如 `192.168.1.20`。
3. 把这个名字加进白名单：`JARVIS_ALLOWED_HOSTS=192.168.1.20`，重启。
4. 手机浏览器打开 `http://192.168.1.20:3081/`，会自动跳到 `/pair`
   （或手动打开）。电脑上 **设置 → 设备 → 生成配对码**，输入六位数字。
5. 配对成功后“添加到主屏幕”。

**不要**把 3081 端口直接映射到公网。跨网络请用 Tailscale / WireGuard 这类私有网络，
或者给 Jarvis 配 TLS（`JARVIS_TLS_CERT` / `JARVIS_TLS_KEY`）后再暴露。

## 6. 第一次用，试这几句

- “记住：我周五下午要交季度报告。”（存进记忆，之后能查）
- “我上次说周五要干什么？”（召回）
- “帮我把这段话改得更正式：……”（改写）
- “看下屏幕，告诉我这个报错是什么意思。”（Linux，需要授权弹窗）

右侧三个标签页分别是记忆、提醒、运行状态。点右上角 **观察台** 能看到
注意力、延迟、记忆关系的实时视图。

## 7. 隐私：默认发生了什么

- 对话、记忆、提醒都存在本机 SQLite（`~/.local/share/jarvis/data/`）。
- 用本地模型时，内容不出网。
- 用远端模型时，**当前对话 + 普通记忆**会发给你选的供应商；
  标记为 sensitive/secret 的记忆不会进入上下文。
- 屏幕/摄像头画面默认不发远端（需要显式 `JARVIS_ALLOW_REMOTE_VISION=1`）。
- “设置 → 系统 → 导出/擦除”可以带走或彻底删掉本机数据。

## 8. 卡住了看哪里

| 现象 | 先看 |
|---|---|
| 打不开页面 | `npm run doctor`；端口是否被占用 |
| 对话报“额度不足” | 设置里优先级是否有第二个供应商 |
| 手机打不开 | 同一 Wi-Fi？`JARVIS_HOST` 与 `JARVIS_ALLOWED_HOSTS` 是否配好 |
| 想要日志 | 数据目录下的 `jarvis.log` |
| 想彻底重来 | 设置 → 系统 → 擦除全部本机数据 |
