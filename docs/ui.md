# Jarvis Web UI：布局、外观与实时协议

> 这份文档只描述浏览器端（`web/`）与它和服务之间的契约。服务端边界见
> [security.md](security.md)，观察台见 [observatory.md](observatory.md)。

## 0. 独立页面

| 路径 | 作用 | 是否需要登录 |
|---|---|---|
| `/` | 主应用 | 是（loopback 例外） |
| `/providers` | 模型 + 语音服务指南：分区筛选、每家的步骤/地址/费用/坑、常见模型/音色标签（点击复制），一键带回设置 | 否（目录是公开信息） |
| `/install` | 按设备给出安装步骤，识别系统与浏览器 | 否 |
| `/pair` | 手机配对 | 否 |

`/providers` 和 `/install` 与主应用共用 `styles.css` 的配色变量和
`theme-boot.js`，所以深浅色一致；两者都列进了 Service Worker 的 shell 缓存。

## 1. 布局

- 顶栏：品牌、连接状态、当前模型/供应商、时钟、主题切换、观察台、专注、设置。
- 左栏（presence）：状态球、状态文案、快捷动作（看屏幕 / 看摄像头 / 记住 / 今日简报）。
- 中间：对话流 + 输入框。输入框左侧是**场景**下拉，右侧是麦克风与发送。
- 右栏：记忆 / 提醒 / 运行 三个标签页（`role=tablist`，带 `aria-controls`）。
- 窄屏（≤960px）：左栏折叠为顶部状态区，右栏移到下方；观察台与设置均为全屏抽屉。

## 对我的了解

顶栏人物图标打开原生资料对话框。资料、职业经历、兴趣偏好、目标、Jarvis 的理解与家庭人物均可直接编辑；模型建议显示「待确认」，用户保存后成为确认信息。未填写字段不会猜测，页面不显示虚构的熟悉度分数。编辑带版本号，其他窗口已更新时返回 409 并保留草稿，需显式放弃草稿才能载入新版本。

所有事实仍属于本地 `jarvis.db` 的 `memory_items`；结构化值、资料条目和人物在同一数据库，修改与删除同步到记忆视图。人物关系独立于用户本人。基本字段为性别、生日、自报年龄、城市、行业、岗位；生日支持公历/农历与闰月，年份可省略。完整日期可计算周岁和以农历新年为界的生肖，星座使用常见日期区间并标明近似。农历计算支持 1900–2100；无年份不会猜年龄或生肖。生日不会自动创建提醒。

单条资料选择「仅展示」「仅本地模型」「相关时可用于模型」；身份和家庭等字段即使选相关使用仍不发送远端。实际使用的条目以 ID 记录，回答下方可打开对应当前版本。已经删除的资料不能还原展示。使用本地资料的请求固定到验证过的本地客户端，不向远端故障转移。所有引用画像的问答及提取出画像的来源回合保留在可见历史，但排除后续模型上下文，防止旧信息绕过订正或隐私设置。

「持续学习」和「回答时使用」分别控制自动新增与调用。自动画像提取只使用本地模型，要求用户第一人称原句证据，暂支持爱好、城市、岗位、行业及沟通偏好，不回扫全部旧会话。用户订正或忘记后保存内容/来源/字段指纹阻止受支持字段的自动重建；指纹不保存原文，手动重新填写仍允许。该机制不能识别所有任意语义改写。全量清空删除资料、人物、指纹与设置；普通历史删除不删除独立记忆。已发送到模型或用户已看到的内容不能撤回。

接口：`GET /api/profile`；`POST /api/profile/entries`、`DELETE /api/profile/entries/:id`；`POST /api/profile/people`、`DELETE /api/profile/people/:id`；`PATCH /api/profile/settings`；`GET /api/profile/entries/:id/source`。来源只返回可用的用户原文，手动填写及已删除来源显示不可用原因。所有接口沿用认证、同源与不缓存规则；隐私导出和 SQLite 备份自动包括资料。

浏览器回归脚本 `scripts/profile-ui-smoke.ts` 要求显式隔离服务 URL，拒绝生产 3081。覆盖资料编辑、派生生日、家庭、直接订正、学习暂停、草稿、冲突、删除和主题/窄屏。它创建合成测试资料，不能用于用户数据目录。

## 会话与历史

对话区顶部显示当前标题，提供「新对话」和「历史」。历史使用原生对话框，支持标题和正文搜索、重命名、归档/取消归档、JSON 导出、单条删除和清空。删除有二次确认，清空须输入 `DELETE ALL SESSIONS`。归档后保留记录，取消归档才能继续发送。

当前会话选择保存在浏览器；草稿仅在当前页面内按会话保留，不把聊天正文写入 localStorage。服务端把完整文本存入独立 `sessions.db`，刷新和重启后可恢复；列表每页 50 条，消息每页 100 条，可加载更早记录。旧版本只有摘要记忆，不能还原为完整会话，不进行伪造迁移。

全局只同时处理一个用户回合。处理期间可浏览或新建其他会话，发送等待当前回合结束。WS/HTTP/语音携带 `sessionId`、客户端 UUID `turnId`；重复回合只返回已有结果，不重复执行。取消按身份匹配，模型、ASR、TTS 退出前保留占用。连接恢复和回合结束都拉取数据库快照，已保存消息不会重新自动播音。服务器重启将未完成消息标为错误；部分回复保留，可新发一条继续。

历史只在同一会话内、按完整成功的问答对进入受限上下文；失败、取消及感知/记忆等非普通聊天结果不自动带入后续模型对话。长期记忆独立存在，删除会话不会删除已形成的记忆。系统「清空所有数据」才会同时清除二者，并先阻断新请求、停止和等待在途工作。

备份包含存在的 `sessions.db`；恢复前验证数据库完整性和版本。旧备份没有该库时保留当前会话库。备份中的每个数据库分别一致，跨库不保证同一事务时刻；需要严格跨库时间点时先停服务再备份。

会话 API：`GET/POST/DELETE /api/sessions`、`GET/PATCH/DELETE /api/sessions/:id`、`GET /api/sessions/:id/export`。列表接受 `query/limit/offset/archived`；消息接受 `limit/before`（数字消息 ID）。详情的 `activeTurn` 是全局运行身份。活动会话不能删除或归档，忙碌时不能清空；冲突返回 409，已删除会话返回 404。所有会话接口遵循认证与同源约束，响应不进入 Service Worker 缓存。

浏览器回归：对临时数据目录启动独立服务，再运行 `JARVIS_URL=http://127.0.0.1:<测试端口> node --experimental-transform-types scripts/session-ui-smoke.ts`。该脚本会清空测试服务的所有会话，拒绝默认生产端口 3081；Chrome CDP 默认 9223，可用 `JARVIS_CDP_URL` 指定。`scripts/session-stream-smoke.ts` 另起临时模拟 HTTP/WS 服务，验证流式切换、迟到快照、重连及重复文字回合，不访问生产数据。

## 2. 设置（5 个标签）

| 标签 | 内容 |
|---|---|
| 模型 | 本地/远端切换、三种协议、模型发现（目录常见型号兜底）、向量/视觉自动补全、供应商池、优先级、工作场景、保存 |
| 语音 | ASR/TTS 各自一条优先级链（可多服务、↑↓ 调序、本地引擎可作兜底）、厂商适配器（OpenAI 兼容 / Gemini / Cloudflare / Edge）、冷却状态、试听 |
| 外观 | 发送快捷键（Enter / Ctrl+Enter，当前浏览器自动保存）、主题色相、预设、动效强度、密度、模糊、粒子、字号（服务端 `ui.*` 调参） |
| 设备 | 配对码、设备列表、撤销、远程访问说明 |
| 系统 | 运行态、诊断、导出、擦除、首次引导重放 |

页签支持左右方向键、Home/End；切走前若有未保存修改会提示。设置弹窗是唯一
`settings-modal`，动作确认使用独立弹层，互不覆盖。

## 3. 外观与主题

- 深色/浅色/跟随系统由顶栏按钮循环切换，存在浏览器 `localStorage['jarvis.theme']`，
  **只影响当前浏览器**；首屏由 `theme-boot.js` 预先设好，避免闪白。
- 主题色、动效、密度、字号属于服务端调参（`PUT /api/tuning`），对所有设备生效，
  写入 `data/tuning.json`。
- 颜色通过两个变量分发：`--accent-h`（色相）与 `--accent-rgb`（通道）。
  改色必须同时更新两者，否则会出现“只有一半界面变色”。
- 遵循 `prefers-reduced-motion`；系统设置优先于界面里的动效强度。

## 4. PWA 与离线

`web/sw.js` 是 network-first 的 shell 缓存，版本号在 `CACHE` 常量（当前
`jarvis-shell-v19`）：

- 只缓存 GET 同源请求；`/api/*`、`/ws`、带 `token` 参数的 URL 一律不缓存。
- 导航请求离线时回退到 `/`；脚本/样式等非导航请求离线返回 503，不会把 HTML 当 JS。
- `install` 时 `skipWaiting()`，`activate` 时清理旧缓存并 `clients.claim()`。
- **改了 `web/` 下任何资源都要同时提升 `CACHE` 版本**，否则旧 shell 会继续生效。

## 5. 浏览器 ↔ 服务端 WebSocket

入口 `ws://<host>:<port>/ws`；同源 Cookie 或 `?token=`（仅 WS 接受查询参数）。

客户端 → 服务端：

```json
{ "kind": "chat", "text": "…", "scenario": "coding" }
{ "kind": "cancel" }
{ "kind": "ping" }
```

服务端 → 客户端：

```json
{ "kind": "hello", "recent": [ ...最近 30 条事件... ] }
{ "kind": "event", "event": { "type": "assistant.delta", "data": { "text": "…" } } }
{ "kind": "pong" }
{ "kind": "error", "error": "…" }
```

关键事件：`assistant.delta`（流式增量）、`assistant.done`（完成，含 turnId）、
`assistant.scenario`（本轮场景）、`model.failover`（自动换供应商）、
`sense.capture`（采集卡片）、`memory.pinned`、`tuning.changed`、`voice.changed`、
`turn.start`、`user.message`、`runtime.ready`、`attention.*`。
`model.failover` 走 WebSocket 广播，**没有 SSE 端点**。

## 6. 键盘

- `Enter` 发送，`Shift+Enter` 换行；输入框聚焦时麦克风按钮可用 `Space` 切换录音。
- `#orb`（状态球）同样可聚焦，`Enter` / `Space` 切换录音。
- `Esc` 关闭最上层弹层（动作确认 → 设置 → 大图预览）。
- 所有弹层都有 Tab 焦点陷阱，关闭后焦点回到打开它的控件；
  观察台打开时主界面 `inert`。
