# Jarvis Web UI：布局、外观与实时协议

> 这份文档只描述浏览器端（`web/`）与它和服务之间的契约。服务端边界见
> [security.md](security.md)，观察台见 [observatory.md](observatory.md)。

## 0. 独立页面

| 路径 | 作用 | 是否需要登录 |
|---|---|---|
| `/` | 主应用 | 是（loopback 例外） |
| `/providers` | 模型 + 语音服务指南：分区筛选、每家的步骤/地址/费用/坑、常见模型/音色标签（点击复制），一键带回设置 | 否（目录是公开信息） |
| `/install` | 按设备给出安装步骤，识别系统与浏览器 | 否 |
| `/pair` | 手机配对 | 否 |

`/providers` 和 `/install` 与主应用共用 `styles.css` 的配色变量和
`theme-boot.js`，所以深浅色一致；两者都列进了 Service Worker 的 shell 缓存。

## 1. 布局

- 顶栏：品牌、连接状态、当前模型/供应商、时钟、主题切换、观察台、专注、设置。
- 左栏（presence）：状态球、状态文案、快捷动作（看屏幕 / 看摄像头 / 记住 / 今日简报）。
- 中间：对话流 + 输入框。输入框左侧是**场景**下拉，右侧是麦克风与发送。
- 右栏：记忆 / 提醒 / 运行 三个标签页（`role=tablist`，带 `aria-controls`）。
- 窄屏（≤960px）：左栏折叠为顶部状态区，右栏移到下方；观察台与设置均为全屏抽屉。

## 工具与 MCP

设置 → **MCP**打开面向普通用户的预置目录；**高级：自定义 MCP**保留自定义服务器、工具目录和调用记录。模型来源的高级设置中需显式开启「原生工具调用」；不支持的模型保留普通聊天。每轮工具请求固定到实际选中的具体模型，避免后续工具结果跨供应商故障转移。Ollama、OpenAI Chat Completions / Responses、Anthropic 均使用原生协议。

调用确认展示具体参数、会话与回合；同意仅适用于这一项调用，过期、取消或配置变化后不能继续执行。结果未知表示操作可能已经执行，不等于失败或撤销；系统停止后续调用，不自动重放。历史回答可打开对应调用记录；重启将未完成调用标为未知。执行记录与会话同库，删除会话会级联删除，导出附带调用记录，SQLite 备份完整保留。

MCP 支持 stdio 和 Streamable HTTP，默认服务器停用、工具需确认、返回结果仅本地、目标可能出网、有副作用。工具的本地数据处理许可、返回结果共享范围、执行确认分别配置；本地进程并不等于沙箱或离线。远端仅允许 HTTPS（loopback 可 HTTP），拒绝所有重定向。凭据只保存在私有配置，界面不返回命令参数、完整 URL 或密钥；编辑留空保留，明确清除才删除。Linux 配置锁依赖 `/usr/bin/flock`，进程崩溃后自动释放。普通备份不包含 MCP 凭据；使用 `--include-secrets` 才包含完整 MCP 配置，恢复时保留原配置备份并设置私有权限。

资源列表和读取按需调用；不转发服务器系统指令，不启用 sampling、elicitation、OAuth、订阅或 MCP prompt 模板。工具定义和输出 schema 在可终止的限时线程中校验。MCP 返回文本/结构化结果有大小上限，二进制不直接进入模型。超过模型预算的目录不会全部暴露；模型可用 `tool_search` 按需发现外部工具，下一步经隐私与容量复检加载定义。工具结果保留调用/结果配对，过长内容缩短并明确标注。使用本地结果及未知结果的回合从后续上下文和摘要中排除。

接口：`GET /api/tools`、`GET /api/tools/calls?sessionId=…&turnId=…`、`POST /api/tools/approvals/:id`；`GET /api/mcp`、`POST /api/mcp/servers`、`DELETE /api/mcp/servers/:id`、`POST /api/mcp/servers/:id/reconnect`。配置修改使用版本校验，忙碌时返回 409；不会中途切换执行权限。全量隐私清空包含 MCP 配置及凭据，普通记忆删除保留配置。

### 服务连接：只填写必要凭据

目录按「生活」「办公」「开发」「通用」分类，可搜索名称和说明。用户不需要填写服务 URL、启动命令、协议或 JSON：这些由预置配置维护。每张卡片的「设置、用法与限制」包含申请步骤、提问示例、账号前置条件，以及「官方凭据设置」「官方使用文档」「前往服务商撤销授权」链接。可配置表示 Jarvis 提供对应接入模板，不代表每个账号都具有服务权限。

连接顺序为 **连接服务 → 保存配置 → 验证连接 → 手动启用**。保存新凭据或更新已有字段会先停用连接并要求重新验证；验证成功不会自动启用。验证只执行 MCP 初始化和工具发现，不执行真实业务查询，因此不能证明密钥有余额、拥有目标资源权限或全部接口可用。和风、飞书的本地适配器尤其需要在启用后通过明确的真实查询检验服务商认证；真实查询可能消耗额度。目录状态包括未配置、已停用、连接中、已连接、连接失败、待验证；错误说明不能代替服务商控制台中的账号状态。

已保存的字段不回显，编辑时留空保留原值；只有本次填写的字段会提交。凭据草稿只保留在当前表单，关闭或取消编辑会清空。版本冲突保留草稿且不自动重试，用户需明确重新加载并丢弃草稿。连接动作与其他模型、工具配置变更共享忙碌和版本检查，不能在执行途中悄悄切换凭据或权限。

当前八个可配置预置均只读，只允许目录内明确列出的查询工具；服务商新增或未知工具默认禁止，不能凭工具自报的只读注解自动放行。返回内容默认仅供本地模型使用，服务请求按远端目标处理，包括以 stdio 启动、实际调用公网 API 的和风和飞书适配器。本机进程不等于离线或沙箱。预置连接由服务目录管理，高级自定义界面不能借用保留的预置 ID，或改写其地址、命令及策略。

三个管理动作分别是：**停用**停止后续调用但保留凭据；**断开并清除本地凭据**删除 Jarvis 保存的连接与凭据；**前往服务商撤销授权**打开官方管理入口，由用户撤销 Token 或应用授权。断开本机不撤销其他客户端的授权。凭据存于权限 `0600` 的私有 `mcp-config.json`，不返回模型或浏览器；只有 `--include-secrets` 备份才纳入该文件。恢复时所有 MCP 连接均停用，预置验证时间与验证指纹被清除，需重新验证并手动启用；即使备份未包含密钥而保留目标环境原有凭据，也会撤销这些连接的启用状态。此操作不撤销服务商授权，仍应检查凭据有效期和资源权限。验证连接也不构成带真实凭据的端到端验收。

服务目录接口为 `GET /api/mcp/services`、`POST /api/mcp/services/:id/configure`、`POST /api/mcp/services/:id/verify`、`POST /api/mcp/services/:id/toggle` 和 `DELETE /api/mcp/services/:id`；变更携带 `expectedRevision`。高级自定义 MCP 接口继续保留，不绕过预置连接保护。

## 本地工具、任务与目录授权

设置 → 工具管理目录授权、联网、Shell 和技能目录；会话入口显示任务计划、后台任务与产物。目录授权默认留空，联网和 Shell 默认关闭，技能目录默认未配置。服务创建独立的 `artifacts` 输出目录，供文件产物和受限 Shell 使用；输出目录由服务管理，不能通过配置接口改成其他目录。可写目录也允许文件工具读取，但文件工具的目录授权不授予 Shell 访问权。

配置保存携带 `expectedRevision`；版本冲突返回 409，页面保留草稿，需主动重新加载。修改配置前先停止并等待当前对话、工具和后台任务，防止撤销与执行交错。模型工具目录按实际配置、权限、后端能力和上下文容量加载，工具出现在目录中不代表获得批准或其依赖已可用。

### 实际工具目录

主程序提供四十余个内置工具（含 `tool_search`，不含 MCP）。联网、技能和 Shell 等条件不满足时不会全部出现；每轮模型请求只加载符合权限和容量的子集。

| 分组 | 工具名称 | 行为 |
|---|---|---|
| 发现 | `tool_search` | 搜索内置和 MCP 工具；下一步重新校验后加载 |
| 时间与计算 | `current_time`、`calculate`、`time_convert`、`time_difference` | 有界算术、兼容单位换算、明确时区的时间转换与时间差；浮点运算不保证财务精度，时间差的天数按 24 小时计算 |
| 提醒 | `reminders_list`、`reminder_create`、`reminder_update`、`reminder_cancel`、`reminder_complete` | 单次及每日/每周重复提醒，写操作需批准 |
| 记忆与画像 | `memory_search`、`memory_read`、`memory_propose`、`memory_correct`、`memory_forget`、`profile_read` | 普通记忆检索、原文与来源、候选及订正/遗忘；画像仅按本地上下文许可读取 |
| 历史 | `session_search`、`session_read` | 搜索和分页读取允许用于上下文的完整成功问答摘录 |

| 产物 | `artifact_create`、`artifact_present` | 创建输出文件，或登记已存在的获准文件供该会话下载 |

### 问题、批准与后台任务

“需要你补充信息”与工具批准是独立弹窗。问题最多四项，可单选、多选或填写文字；回答必须匹配原问题、会话和回合，默认两分钟到期。过期、取消、回合结束或配置更新后不能补交；没有回答不等于批准。回答只补充任务信息，不授予文件、网络或其他工具权限。

任务计划、问题与任务状态存入独立私有数据库。后台任务返回任务 ID 和实际状态；前台等待结束可能只是转为后台运行，不能当作执行完成。输出有内联与落盘大小限制，截断会标明。取消先请求停止，终态只在进程退出后记录，已完成的文件写入不回滚。进程可以在当前服务运行期间持续执行；服务重启后旧运行任务标为 `interrupted`、旧问题取消，不恢复进程，也不重放命令。需查看输出并由用户决定是否重新执行。

Shell 依赖 Linux `/usr/bin/bwrap` 和可用的隔离能力；探测失败时保持不可用，不降级到宿主直接执行。沙箱仅挂载只读系统运行时和二进制目录（如 `/usr`、`/bin`、`/lib`），以及可写的 Jarvis 输出目录；使用独立临时目录、进程/网络隔离和清理后的环境，不继承宿主凭据或网络连接。它不能读取文件工具授权的外部目录，也不提供任意联网 Shell。启用开关不代替每次执行批准。

### 文件版本、交付与清空

文件操作限定在明确授权目录及输出目录；私有应用存储、受保护凭据路径、特殊文件系统、符号链接及硬链接文件受到限制。普通文件读取最多 1 MiB，搜索为字面匹配并限制深度、扫描文件数、总字节数与时间；默认不遍历隐藏项。图片检查需配置可用的本地视觉模型，支持受限大小的 PNG/JPEG/WebP，不能靠文本模型虚构视觉结果。

已有文件写入/编辑要求读取时返回的 SHA-256 `expectedVersion`，文件已变化即冲突；新文件不覆盖已存在目标。替换前保存私有恢复历史；恢复仍需原路径授权及当前版本。此机制提供内部串行写入与版本检查，不承诺抵御外部恶意进程在最终检查后的目录搬移或竞态写入。备份历史是私有权限的本地文件，不是加密保险库。

产物登记指向真实源文件并记录内容哈希，不复制成永久快照。之后修改、移走、删除文件或撤销权限，原下载可能不可用，需重新登记当前版本；外部源文件不会因登记而归 Jarvis 所有。

**全量隐私清空会删除整个 Jarvis 专用输出目录中的内容，包括已经修改的产物、未登记文件及 Shell 生成文件。不要把需要独立保留的原件放进这个工作目录。** 清空同时移除私有恢复历史、产物目录、问题、计划、任务输出并撤销目录/联网/Shell/技能配置。外部授权目录中的原件不会被删除，先前获准对外部文件作出的修改也不会自动撤销。单会话删除清理该会话拥有的记录与可确定归属的产物，不等于清空整个共享输出目录。

### 记忆、历史与出网

`memory_propose` 只能从当前用户原句提出低信任候选；执行批准后仍是待确认候选，需要用户确认才能成为长期事实。订正和遗忘要求当前记忆版本并排除相关旧来源、使摘要失效；成功后本轮直接返回确定性确认，不再将修改前的事实发送给下一次模型请求。普通记忆工具不允许借此改写个人画像。

历史检索只返回完整成功且未被隐私排除的问答摘录，不读取工具参数、批准记录、工具结果或摘要缓存。画像“仅展示”内容不会通过 `profile_read` 进入模型。文件、技能、任务回答、个人数据和感知结果保持本地；本轮取得本地结果后不再调用远端工具。不能用历史搜索重新引入已排除的回合。

开启联网后，查询词和 URL 会发送到外部服务。DuckDuckGo 搜索无需配置账号，但可因限流、页面格式变化或服务不可用失败；返回来源 URL、抓取时间和有界摘录，不保证搜索完整性。抓取只允许匿名公开 HTTP(S)，检查 DNS 和重定向目标、固定已验证地址、限制时间和响应体，防止通过 URL 访问内网；这些检查不意味着网页内容可信。网页和搜索结果始终是外部数据，不能授予权限或覆盖用户指令。

技能目录是独立明确授权，只读取有界、非链接的可用 Markdown 文件。指引保持本地并标记为不可信用户配置内容；加载不执行 Shell、安装依赖或扩大权限。当前没有长期目标自动续行、多代理、浏览器自动点击，也不会自动连接邮箱、日历等外部账号；此类集成需另行配置适用 MCP 服务。

### 重复提醒

重复规则支持 `daily` 和 `weekly`，使用明确的 IANA 时区与当地 `HH:mm`，每周规则采用 ISO 星期一 1 至星期日 7。日期换算输出 UTC 存储值和带时区的下次显示时间，界面及回复应使用后者。编辑要求 `expectedRevision`；完成循环提醒只完成当前一次并保留下一次，取消则停止整个系列。

夏令时不存在的当地时间跳过，重复出现的时间只触发较早一次。服务停机错过多次时合并为一次到期通知，再安排未来一次，不逐条补发全部历史。调度采用先持久标记、后通知的至多一次语义：在二者之间崩溃可能漏掉那次通知，不能保证恰好一次。提醒只通知，不会在到点时自动执行任意工具；当前不支持 cron 规则。

### 备份、恢复与接口

普通备份包括本地工具配置、任务数据库、产物目录、文件恢复历史和任务输出；这些可能含完整私人文本，即使未加 `--include-secrets`，备份也应按私人数据保管。供应商和 MCP 凭据仍只有 `--include-secrets` 才纳入。恢复时重定位内部输出路径，并默认撤销外部读写目录、联网、Shell 和技能授权；需要在新环境重新确认，不自动恢复执行中进程或待回答问题。

各 SQLite 库分别生成一致快照，但多个库、配置、文件历史和产物不处于同一跨文件事务；**需要可对应的完整备份时先停止 Jarvis，再备份**。恢复也应先停服务；备份不是对外部授权目录的全盘备份。

接口：`GET /api/local-tools`、`PATCH /api/local-tools/settings`、`POST /api/local-tools/questions/:id`、`GET /api/local-tools/session/:sessionId`、`POST /api/local-tools/jobs/:id/cancel`、`GET /api/local-tools/artifacts/:id?sessionId=…`。问题回答包含会话和回合，取消任务及下载包含会话标识；沿用现有认证、同源和不缓存规则。问题、计划、任务和产物经 WS 推送更新，会话/隐私导出附带本地工具记录。

## 对我的了解

顶栏人物图标打开原生资料对话框。资料、职业经历、兴趣偏好、目标、Jarvis 的理解与家庭人物均可直接编辑；模型建议显示「待确认」，用户保存后成为确认信息。未填写字段不会猜测，页面不显示虚构的熟悉度分数。编辑带版本号，其他窗口已更新时返回 409 并保留草稿，需显式放弃草稿才能载入新版本。

所有事实仍属于本地 `jarvis.db` 的 `memory_items`；结构化值、资料条目和人物在同一数据库，修改与删除同步到记忆视图。人物关系独立于用户本人。基本字段为性别、生日、自报年龄、城市、行业、岗位；生日支持公历/农历与闰月，年份可省略。完整日期可计算周岁和以农历新年为界的生肖，星座使用常见日期区间并标明近似。农历计算支持 1900–2100；无年份不会猜年龄或生肖。生日不会自动创建提醒。

单条资料选择「仅展示」「仅本地模型」「相关时可用于模型」；身份和家庭等字段即使选相关使用仍不发送远端。实际使用的条目以 ID 记录，回答下方可打开对应当前版本。已经删除的资料不能还原展示。使用本地资料的请求固定到验证过的本地客户端，不向远端故障转移。所有引用画像的问答及提取出画像的来源回合保留在可见历史，但排除后续模型上下文，防止旧信息绕过订正或隐私设置。

「持续学习」和「回答时使用」分别控制自动新增与调用。自动画像提取只使用本地模型，要求用户第一人称原句证据，暂支持爱好、城市、岗位、行业及沟通偏好，不回扫全部旧会话。用户订正或忘记后保存内容/来源/字段指纹阻止受支持字段的自动重建；指纹不保存原文，手动重新填写仍允许。该机制不能识别所有任意语义改写。全量清空删除资料、人物、指纹与设置；普通历史删除不删除独立记忆。已发送到模型或用户已看到的内容不能撤回。

接口：`GET /api/profile`；`POST /api/profile/entries`、`DELETE /api/profile/entries/:id`；`POST /api/profile/people`、`DELETE /api/profile/people/:id`；`PATCH /api/profile/settings`；`GET /api/profile/entries/:id/source`。来源只返回可用的用户原文，手动填写及已删除来源显示不可用原因。所有接口沿用认证、同源与不缓存规则；隐私导出和 SQLite 备份自动包括资料。

浏览器回归脚本 `scripts/profile-ui-smoke.ts` 要求显式隔离服务 URL，拒绝生产 3081。覆盖资料编辑、派生生日、家庭、直接订正、学习暂停、草稿、冲突、删除和主题/窄屏。它创建合成测试资料，不能用于用户数据目录。

## 会话与历史

对话区顶部显示当前标题，提供「新对话」和「历史」。历史使用原生对话框，支持标题和正文搜索、重命名、归档/取消归档、JSON 导出、单条删除和清空。删除有二次确认，清空须输入 `DELETE ALL SESSIONS`。归档后保留记录，取消归档才能继续发送。

当前会话选择保存在浏览器；草稿仅在当前页面内按会话保留，不把聊天正文写入 localStorage。服务端把完整文本存入独立 `sessions.db`，刷新和重启后可恢复；列表每页 50 条，消息每页 100 条，可加载更早记录。旧版本只有摘要记忆，不能还原为完整会话，不进行伪造迁移。

全局只同时处理一个用户回合。处理期间可浏览或新建其他会话，发送等待当前回合结束。WS/HTTP/语音携带 `sessionId`、客户端 UUID `turnId`；重复回合只返回已有结果，不重复执行。取消按身份匹配，模型、ASR、TTS 退出前保留占用。连接恢复和回合结束都拉取数据库快照，已保存消息不会重新自动播音。服务器重启将未完成消息标为错误；部分回复保留，可新发一条继续。

历史只在同一会话内、按完整成功的问答对进入受限上下文；失败、取消及感知/记忆等非普通聊天结果不自动带入后续模型对话。长期记忆独立存在，删除会话不会删除已形成的记忆。系统「清空所有数据」才会同时清除二者，并先阻断新请求、停止和等待在途工作。

### 上下文预算与自动摘要

每轮普通文本聊天统一估算系统指令、当前输入、画像、记忆、会话摘要和近期消息。模型设置的高级区域可填写实际上下文容量（默认未知模型为 4096 tokens）；模型路由使用可用故障转移链的最小窗口，场景指定未知型号时保守上限 4096。输出默认预留窗口的四分之一、显式请求最多一半，另预留至少 128 tokens 或窗口 8% 的安全空间。估算采用 UTF-8 字节数/2 加消息开销，是针对中文更保守的近似值，不是精确 tokenizer，不保证所有模型都不溢出。

历史压力或条数超过预算时，较早完整成功问答分段送给验证过的本地模型生成精简摘要，保留近期原文。摘要请求本身也核算本地窗口，单次输出最多 512 tokens；一轮最多八次分段整理，每次最长 45 秒，可取消。摘要必须非空、没有被输出上限截断、估算严格变短，且提交时来源版本未变化。模型不可用、内容无法拆分或摘要失败时降级为预算内的近期完整问答；页面说明整理或裁剪状态，不删除原始历史。超过 10,000 条待处理消息时优先保留最新问答，不把分页开头误当近期内容。用户将历史消息条数设为 0 或 1 时，不带会话摘要与问答对。

摘要作为 `sessions.db` v2 派生记录保存，包含来源 ID、覆盖游标、作用域和版本；重启后可以复用。完整聊天导出仍导出原文，SQLite 备份包含摘要。排除来源、订正/删除记忆、资料设置变更使相关摘要失效；删除会话及全量清空级联删除摘要。不能把画像来源或已排除的回合重新放进摘要；摘要不会升级为已确认个人事实。所有摘要生成保持本地，不使用远端故障转移；由可用于普通对话的历史形成的摘要可随普通对话发送给用户选择的远端模型。

若提供方明确报告上下文溢出且尚未输出任何回复，最多以更小预算重建后再试一次；请求没有变小则停止。已输出部分内容时不重试，避免重复文本或播音。当前输入加必要指令本身放不下时，提示缩短输入或选择更大窗口。通用网络错误不被误判为上下文溢出。

备份包含存在的 `sessions.db`；恢复前验证数据库完整性和版本。旧备份没有该库时保留当前会话库。备份中的每个数据库分别一致，跨库不保证同一事务时刻；需要严格跨库时间点时先停服务再备份。

会话 API：`GET/POST/DELETE /api/sessions`、`GET/PATCH/DELETE /api/sessions/:id`、`GET /api/sessions/:id/export`。列表接受 `query/limit/offset/archived`；消息接受 `limit/before`（数字消息 ID）。详情的 `activeTurn` 是全局运行身份。活动会话不能删除或归档，忙碌时不能清空；冲突返回 409，已删除会话返回 404。所有会话接口遵循认证与同源约束，响应不进入 Service Worker 缓存。

浏览器回归：对临时数据目录启动独立服务，再运行 `JARVIS_URL=http://127.0.0.1:<测试端口> node --experimental-transform-types scripts/session-ui-smoke.ts`。该脚本会清空测试服务的所有会话，拒绝默认生产端口 3081；Chrome CDP 默认 9223，可用 `JARVIS_CDP_URL` 指定。`scripts/session-stream-smoke.ts` 另起临时模拟 HTTP/WS 服务，验证流式切换、迟到快照、重连及重复文字回合，不访问生产数据。

## 3. 外观与主题

- 深色/浅色/跟随系统由顶栏按钮循环切换，存在浏览器 `localStorage['jarvis.theme']`，
  **只影响当前浏览器**；首屏由 `theme-boot.js` 预先设好，避免闪白。
- 主题色、动效、密度、字号属于服务端调参（`PUT /api/tuning`），对所有设备生效，
  写入 `data/tuning.json`。
- 阅读字号按层级统一：正文与表单输入约 16px，导航与标签 14px，说明 13–14px，常规辅助标记至少 12px；标题保留独立层级，密集图表刻度单独处理。现有字号缩放继续生效，窄屏不通过缩小正文来塞入内容。
- 颜色通过两个变量分发：`--accent-h`（色相）与 `--accent-rgb`（通道）。
  改色必须同时更新两者，否则会出现“只有一半界面变色”。
- 遵循 `prefers-reduced-motion`；系统设置优先于界面里的动效强度。

## 4. PWA 与离线

`web/sw.js` 是 network-first 的 shell 缓存，版本号在 `CACHE` 常量（当前
`jarvis-shell-v40`）：

- 只缓存 GET 同源请求；`/api/*`、`/ws`、带 `token` 参数的 URL 一律不缓存。
- 导航请求离线时回退到 `/`；脚本/样式等非导航请求离线返回 503，不会把 HTML 当 JS。
- `install` 时 `skipWaiting()`，`activate` 时清理旧缓存并 `clients.claim()`。
- **改了 `web/` 下任何资源都要同时提升 `CACHE` 版本**，否则旧 shell 会继续生效。

## 5. 浏览器 ↔ 服务端 WebSocket

入口 `ws://<host>:<port>/ws`；同源 Cookie 或 `?token=`（仅 WS 接受查询参数）。

客户端 → 服务端：

```json
{ "kind": "chat", "text": "…", "scenario": "coding" }
{ "kind": "cancel" }
{ "kind": "ping" }
```

服务端 → 客户端：

```json
{ "kind": "hello", "recent": [ ...最近 30 条事件... ] }
{ "kind": "event", "event": { "type": "assistant.delta", "data": { "text": "…" } } }
{ "kind": "pong" }
{ "kind": "error", "error": "…" }
```

关键事件：`assistant.delta`（流式增量）、`assistant.done`（完成，含 turnId）、
`assistant.scenario`（本轮场景）、`model.failover`（自动换供应商）、
`sense.capture`（采集卡片）、`memory.pinned`、`tuning.changed`、`voice.changed`、
`turn.start`、`user.message`、`runtime.ready`、`attention.*`。
`model.failover` 走 WebSocket 广播，**没有 SSE 端点**。
