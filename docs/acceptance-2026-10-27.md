## 2. 本轮修复（按严重度）

### 严重 / 高

1. **DNS rebinding 可绕过鉴权**（审计实测：伪造 `Host` 可读 `/api/privacy/export`、
   `/api/observatory`，并能发起擦除）。现在所有请求与 WS 升级都校验 `Host`
   白名单（`localhost` / `127.0.0.1` / `[::1]` / `JARVIS_HOST` /
   `JARVIS_ALLOWED_HOSTS`），否则 `421`。新增验收项：陌生 Host → 421。
2. **语音供应商密钥可被“换地址不换 Key”带走**。现在更换 ASR/TTS 服务地址必须
   重新输入 API Key（与模型侧同规则），并先校验 URL（TLS、元数据地址、userinfo）。
3. **“切到本地”不影响选路**：激活只改 `active`，故障转移链仍按旧优先级走。
   现在激活会把该供应商提升到链首，并补了回归测试。
4. **视觉/OCR 出网判定看的是 kind 而不是位置**。现在按 baseUrl 是否 loopback 判定；
   屏幕/摄像头与 OCR 文本只走本机客户端，故障转移不会把它们带到远端。
5. **撤销设备不会断开已建立的 WebSocket**。现在记录每条连接如何通过鉴权，
   撤销/擦除时关闭对应连接，并在消息入口复核授权。新增验收项：撤销后 WS 被断开。
6. **擦除不彻底**：残留远端 API Key、内存里的对话历史与事件回放、日志、WAL 旧页。
   现在擦除会重置模型/语音配置（连 Key）、清空 `Conversation` 与 `EventBus`、
   删除日志、`secure_delete` + `VACUUM` + `wal_checkpoint(TRUNCATE)`、轮换
   `secret.key`、断开所有连接。访问令牌保留（否则会把用户锁在门外）。
7. **敏感记忆仍会被远端 embedder 看到**。现在只有本机 embedder 才会嵌入
   sensitive/secret 记忆；否则只走全文检索（召回评测仍 11/11）。
8. **413 之后连接池中毒**：超限请求未读完 body 就返回，复用连接的下一条请求
   `ECONNRESET`。现在显式 `connection: close` 并排空请求体。
9. **调参接口静默接受非法值**（例如 `ui.motion:'warp'` 返回 200）。现在严格校验：
   枚举越界、非数字、空文本一律 400；数值仍按范围夹紧（滑块可能越界）。
10. **UI 重置调参用错分组 id**（`ui` → `appearance`，请求 400）。
11. **场景保存成功提示不显示**：保存后整卡重渲染，提示写进了已脱离文档的节点。
12. **移动端观察台无法退出**（≤1080px 隐藏了唯一关闭按钮，遮罩点击也点不到）。
    现在顶栏常驻关闭按钮，观察台具备 `role=dialog` + Tab 焦点陷阱 + 背景 `inert`。
13. **动作确认弹窗会摧毁未保存的设置**。现在动作确认有独立弹层，不再复用设置弹窗。
14. **除设置外的弹窗没有焦点陷阱**（感官授权、简报、令牌、首次引导）。已统一。
15. **推送说话只有指针事件**，键盘/读屏无法使用，且 `#orb` 是个可聚焦的死控件。
    现在两者都支持指针按住 + 键盘点击切换。
16. **观察台每 3.2 秒整页重渲染**，输入会被清空、焦点丢失。现在输入聚焦时跳过
    定时刷新，并用 MutationObserver 恢复焦点与光标位置。
17. **`--faint` 对比度 3.1–3.4:1**（不可读）。深色提到 `#86929f`、浅色 `#5f6b78`，
    均过 AA。
18. **`--panel` 变量未定义**，分段控件与场景输入框没有底色。
19. **快捷动作在 ≤960px 只剩图标**、无 `aria-label`。已补。
20. **Service Worker 离线回退**把 JS 请求回成 HTML，且漏缓存 `/pair`、`/pair.js`。
    现在按请求类型回退并升到 `jarvis-shell-v19`。

### 中 / 低（同批处理）

- CSP `connect-src` 从 `ws: wss:`（任意 WS 主机）收紧为 `'self'`。
- `readJson` 拒绝 `null`/数组/原始值（此前会在下游变成 500）。
- `/api/look` 的 `target:'camera'` 在 `vision:true` 时被忽略。
- 配对限流改为按客户端（每分钟 8 次）+ 全局兜底（60 次），一个人刷不进别人的配对窗口。
- 导出补齐提醒、设备列表、不含密钥的配置摘要；UI 与文档同步说明导出范围。
- `api()` 全部请求加上超时（默认 30s，模型测试/列表 60s，简报朗读 90s，语音上传 120s），
  失败不再留下永久禁用的按钮。
- 初始化失败每 3 秒自动重试，不再停在空白页。
- 大图预览支持键盘打开/关闭并恢复焦点；记忆表格行可 Tab + Enter。
- 移动端输入框 16px（避免 iOS 聚焦缩放）、刘海安全区、`<main>` 唯一、
  持久化 `h1`、`role=log` 对话区、`aria-live` 状态文本。
- 观察台图标按钮补 `aria-label`、`aria-pressed`；召回输入跨重渲染保留。

## 3. 验收覆盖（`scripts/acceptance-full.ts`）

静态资源与安全头 → 鉴权（模拟反向代理）→ 跨站与 Host 防护 → 状态与配置读取 →
外观参数 → 记忆（含敏感过滤）→ 对话 → 供应商池与场景 → 语音 → 感知 →
简报/提醒/动作/专注 → 开发数据隔离 → 文件服务边界 → 设备配对与撤销（含 WS 断开）→
WebSocket 协议 → 浏览器交互（可选）→ 重启持久化 → 备份与恢复 → 隐私导出与擦除。

## 4. 已知边界（诚实声明）

- **真实云端账号**只用 mock 验证了协议形状；没有可用 Key，未做真实计费/限流压测。
- **GNOME Portal** 的人工授权弹窗、真实摄像头、真机手机 PWA 未在自动化里覆盖。
- **多用户隔离**不存在：同机同用户进程可读数据目录与令牌，这是单用户模型的前提。
- **局域网名访问**必须显式配置 `JARVIS_ALLOWED_HOSTS`，否则 421 是预期行为。
- 观察台的图节点键盘可达，但 160 个节点的 Tab 顺序仍然偏长；后续可做 roving tabindex。

## 5. 自动化对比度/布局守卫

`npm run ui:smoke` 现在会在真实浏览器里跑一遍计算样式审计（深色 1440、浅色 1440、
浅色 390 三组）：逐元素算 WCAG 对比度（小字 4.5:1、大字 3:1）并检查横向溢出。
它抓到并修掉了浅色主题下 4.2–4.48:1 的六处小字（`.model-pill`、`.settings-chip`、
`.provider-badge`、`.studio-eyebrow`、`.s-pill.green`），以及 21px 高的触摸目标。
审计期间会临时禁用 transition，避免把“渐变中的颜色”误报成低对比度。

### 8.3 过程中修掉的真问题

1. **冷却文件逃过擦除**：`privacy erase` 只删 `voice-config.json`，`voice-health.json`
   还留着服务商 id 与截断的错误文本。补上 `clearHealth()`，并让运行时在擦除后用
   本地默认链重建，否则状态栏仍会显示已擦除的供应商。
2. **4xx 不能静默切换**：最初所有错误都尝试下一个服务，会把“模型名写错”伪装成
   “备用服务也挂了”。现在 `client`/`other` 直接抛错，只有额度/限流/Key/网络/5xx 才切换。
3. **空槽位会变成死链**：旧文件里未配置的 remote 不再塞进链，否则每次请求都先撞
   一个必然失败的 4xx。

### 8.4 诚实边界

- 单测里的“远端”是本地起的 HTTP stub，只证明**协议形状与切换路径**；没有真实调用
  九家 ASR / 八家 TTS 的线上额度，冷却时长是按错误分类推断的。
- Edge TTS 依赖本机 `edge-tts` 命令；命令缺失被归为 `server` 错误（5 分钟冷却）才会切走，
  而不是每次请求都重试。
- 链最多 12 个服务；再多顺序没人维护，校验直接拒绝。
