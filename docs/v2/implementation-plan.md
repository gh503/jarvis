# Jarvis v2 — 实现计划

- Status: Draft；设计评审后冻结
- Date: 2026-10-26
- Related: [jarvis-design.md](jarvis-design.md), [memory-design.md](memory-design.md)

## 1. 原则

1. **纵向切片优先。** 每个里程碑都必须能演示一条完整链路，而不是只完成一个库。
2. **先假后真。** 注意力管理器先用假传感器测试；语音/视觉模型用可替换 adapter。
3. **记忆不阻塞语音。** 热路径只做明确写入；其余异步。
4. **每个切片有验收命令。** 不接受“看起来能用”。
5. **不提前抽象。** 单进程模块化；没有第二个消费者就不拆服务。

## 2. 切片总览

| 切片 | 目标 | 预估 | 退出条件 |
|---|---|---|---|
| M0 | 核心骨架 + 注意力状态机（假传感器） | 3–5 天 | 状态迁移测试全绿；事件可审计 |
| M1 | 语音纵向链路 | 5–8 天 | 按住说话→回答→打断，延迟达标 |
| M2 | 屏幕上下文 | 4–6 天 | “看下这个”能抓当前窗口并回答 |
| M3 | 记忆 v2 最小闭环（记忆子切片 M0–M1） | 6–10 天 | 记住→3 天后召回→可删除 |
| M3.5 | 记忆增强（记忆子切片 M2–M3） | 5–8 天 | 更新/冲突/弃权用例通过；巩固可重跑 |
| M4 | 主动性与摄像头 | 5–8 天 | 会议不打扰；摄像头按需抓帧 |
| M5 | 远程/手机 | 8–12 天 | 手机文字/语音/审批可用 |

预估按“一个人、已有环境、无重大平台坑”计算；Wayland 屏幕捕获和音频路由可能超时。

## 3. M0 — 核心骨架

### 交付

- `jarvis-core` 进程：配置加载、日志、Unix socket、健康检查。
- 事件总线（进程内）：`audio.*`、`attention.*`、`conversation.*`、`memory.*`、`tool.*`。
- `AttentionManager`：
  - 状态：`Idle` / `Listening` / `CapturingUtterance` / `Understanding` / `NeedScreen` / `NeedCamera` / `Responding` / `FollowUp`；
  - 输入：`Wake`、`VadStart`、`VadEnd`、`Cancel`、`IntentNeedsContext`、`ContextReady`、`ContextDenied`、`SpeakDone`；
  - 输出：`StartCapture`、`StopCapture`、`CaptureScreen`、`CaptureCamera`、`Speak`、`Notify`、`Idle`；
  - 所有迁移写 `attention.decision`。
- `ModelAdapter` 接口：`streamText()`、`vision()`、`embed()`；先接一个假实现。
- 审计日志：追加式 JSONL，终端转义，权限 `0600`。

### 测试

- 状态机表驱动测试：合法迁移、非法迁移、取消、超时、打断。
- 假传感器注入：不需要麦克风/摄像头即可跑完整状态流。
- 审计字段完整性测试。

### 验收

```bash
npm run build
npm test
node dist/core-main.js --self-test
```

`--self-test` 输出一次完整的假对话状态迁移，退出码 0。

## 4. M1 — 语音纵向链路

### 交付

- 全局快捷键按住说话（Linux： portal/global shortcut；先做应用内快捷键）。
- 音频采集：PipeWire/PulseAudio，20–40ms PCM 块。
- VAD：本地（Silero VAD 或等价）。
- ASR adapter：本地优先（whisper.cpp / faster-whisper），远端兜底。
- TTS adapter：本地优先（Piper 或等价），远端兜底。
- 对话编排：流式文本 → 分句 → 流式 TTS。
- 打断：用户开口/VAD 触发 → 停止播放、丢弃缓冲、取消请求。
- FollowUp：回答后 5–10 秒追问窗口。
- 延迟打点：`wake_to_capture`、`speech_end_to_asr`、`speech_end_to_first_token`、`speech_end_to_first_audio`、`barge_in_to_stop`。

### 测试

- 假 ASR/TTS：固定文本、固定音频，测试编排和打断。
- 真机 smoke：录一段 3 秒中文，检查 ASR 文本和 TTS 播放。
- 断网：本地 ASR/TTS 仍可用；远端请求明确降级。

### 验收

- 按住说话问“现在几点”，1.5 秒内开始播报。
- 播报中用户说“停”，100ms 内静音。
- 追问“那明天呢”不需要重新按键。
- 延迟报告落盘，p95 可查。

## 5. M2 — 屏幕上下文

### 交付

- XDG Desktop Portal ScreenCast/RemoteDesktop 授权流程。
- 当前窗口元数据：应用名、标题（能拿到才拿）。
- 按需截图：单帧；选区裁剪。
- OCR：本地（Tesseract/PaddleOCR 或等价）。
- 视觉 adapter：本地小模型优先；云端仅 `standard` 隐私级别。
- 意图路由：
  - “这个/这页/这份” → 屏幕；
  - “我这里/手上/桌上” → 摄像头；
  - 低置信 → 问一次。
- 敏感窗口黑名单：密码管理器、网银、私密聊天；命中则拒绝抓取并说明。
- 上下文预算：1 帧 + 1 个 OCR 区域，≤ 4k tokens。

### 测试

- 假截图 + 固定 OCR 文本，测试“看下这个”的路由。
- 黑名单命中：不调用截图 API。
- Portal 拒绝授权：提示，不崩溃。
- 截图不落盘（用临时内存/受控临时文件，完成后删除）。

### 验收

- 打开一份合同 PDF，说“看下这个有什么风险”，Jarvis 抓当前窗口并指出至少一条风险。
- 打开密码管理器，说“看下这个”，Jarvis 拒绝并说明原因。
- 会议屏幕共享时，不自动抓屏。

## 6. M3 — 记忆 v2 最小闭环

### 交付

- SQLite schema：`memory_items`、`memory_episodes`、`memory_entities`、`memory_links`、`memory_events`。
- 迁移：v1 `memory.json` 导入。
- CLI：`memory add/list/show/delete/export`。
- 显式写入：用户说“记住……”→ `confirmed`，来源、时间、敏感级别。
- FTS5 召回：关键词 + 时间 + 置顶。
- 来源渲染：每条记忆带 id、时间、来源、置信度。
- 删除：源 + 投影 + 召回验证。
- 冲突检测 v0：相似/矛盾提示，不静默覆盖。
- 每晚巩固 v0：会话摘要、重复合并、过期失效；先不做向量。
- 记忆查看器：先 CLI，后最小桌面面板。

### 测试

- 写入→重启→召回：内容、来源、时间一致。
- 删除→召回：不再出现；FTS/索引无残留。
- 冲突检测 v0：发现相似/矛盾时标 `proposed` 或提示，不静默覆盖。
- 弃权：无候选时返回 `missing`，不编。
- 迁移：v1 条目数量/id/内容 hash 对齐。

### 验收

- 说“记住我对花生过敏”，3 天后问“晚上吃什么”，能召回并说“这是你之前确认的”。
- 说“忘掉这件事”，删除后不再召回，`memory show` 看不到内容。
- 每条召回都能回答“为什么想起这个”。

## 7. M3.5 — 记忆增强

对应 [memory-design.md](memory-design.md) 的记忆子切片 M2–M3。M3 不阻塞 M4；M3.5 可以与 M4 并行，但必须在“自动提取”默认开启前完成。

### 交付

- 后台抽取：对话/事件结束后异步抽取事实、决定、承诺、截止、人物。
- 重要性分项：`goal/novelty/social/repetition/explicit/deadline`。
- 冲突处理：`supersedes` / `contradicts` 链接；默认展示新条并标注冲突。
- 向量索引：本地 embedding + 混合召回（FTS + 向量 + 时间 + 置顶）。
- 巩固 v1：摘要、合并、失效、衰减、实体链接、索引重建。
- 评测 v0：150 题个人基准，覆盖抽取/多会话/时间/更新/弃权/冲突/隐私。

### 测试

- 知识更新：“我搬家了”后，旧地址失效，新地址可召回。
- 冲突：两个来源矛盾，两条都保留，回答明确标注冲突。
- 弃权：无相关记忆时返回 `missing`，不编。
- 索引重建：删除向量索引后重建，召回结果等价。
- 敏感：`sensitive/secret` 不出现在普通召回/云端 payload。

### 验收

- 更新/冲突/弃权三类用例 ≥ 90% 正确。
- 召回 p95 < 100ms（本地，1 万条以内）。
- 关闭后台抽取，对话延迟无可感知变化。

## 8. M4 — 主动性与摄像头

### 交付

- 触发器：时间、日历、任务截止、设备状态。
- 打扰分数：紧急度、相关性、时效、偏好、打断成本、频道成本。
- 通道：语音 / 浮窗 / 静默队列。
- 免打扰：会议、屏幕共享、麦克风占用、用户说“别烦我”。
- 每日主动语音预算（默认 5 次）。
- 摄像头：按需单帧/3 帧 burst；本地人脸/在场/模糊检测；不存原始视频。
- 摄像头指示灯/状态；一键停止。

### 测试

- 会议场景：触发器命中，但只进静默队列。
- 预算耗尽：不再语音，只文字。
- 摄像头拒绝授权：不重试、不崩溃。
- 低质量帧：回答“没看清”，不猜。

### 验收

- 会议中收到截止提醒，不发声；会后浮窗可见。
- 说“看我手上这个”，抓一帧并回答；说“停”立即停止。
- 主动消息审计包含 `interrupt_score` 和理由。

## 9. M5 — 远程与手机

### 交付

- Gateway：认证、TLS/私网、短期会话、事件流。
- PWA：文字、按住说话、审批、通知。
- WebRTC：手机麦克风/摄像头作为远端输入（第二阶段）。
- 设备撤销、会话过期、断线重连。

### 验收

- 手机配对后可文字对话；撤销后立即失效。
- 手机按住说话，桌面 core 回答；断网恢复后不重复执行。
- 手机审批高风险动作，桌面审计可见。

## 10. 测试策略

| 层 | 方式 |
|---|---|
| 状态机/策略 | 表驱动单元测试，假时钟/假传感器 |
| 记忆 | 临时 SQLite，固定数据集，迁移/删除/冲突用例 |
| 语音 | 假 ASR/TTS 测编排；真机 smoke 测延迟 |
| 屏幕 | 固定截图/OCR 夹具；黑名单/拒绝授权用例 |
| 远程 | 本地 Gateway + 测试客户端；断线/重放/撤销 |
| 隐私 | 敏感记忆不出现在普通召回；云端请求 payload 快照检查 |

## 11. 风险

| 风险 | 缓解 |
|---|---|
| Wayland 屏幕捕获兼容性 | 先支持 Portal；X11 作为回退；M2 第一周做 spike |
| 音频路由/回声 | 先耳机场景；AEC 后置；TTS 打断优先 |
| 本地模型效果不足 | adapter 可切远端；中文基准先测 |
| 记忆抽取过度 | 只抽高置信；`proposed` 不自动确认；评测驱动 |
| 主动性骚扰 | 默认静默；预算/免打扰/反馈调权 |
| 范围膨胀 | M0–M2 不接自动提取/多模态扩展 |
