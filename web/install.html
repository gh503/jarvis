INSTALL

把 Jarvis 装成 App，
以后双击就能用。

Jarvis 是一个跑在你自己电脑上的应用。装成 App 之后没有地址栏、没有标签页， 和普通软件一样；手机上可以“添加到主屏幕”，像微信一样一点就开。 同一个局域网里，手机连的就是这台电脑上的 Jarvis，数据不经过任何第三方。

你的设备怎么装

三种用法，按需要选

① 浏览器直接用（零安装）

打开地址就能用。适合偶尔用、或者借用别人电脑时——记得用完清除本站数据，令牌在浏览器里。

② 装成 App（推荐）

Chrome / Edge 地址栏右侧点“安装”，macOS 用 Safari 的“添加到程序坞”，手机上“添加到主屏幕”。有独立图标、独立窗口、支持离线打开外壳。

③ 常驻后台 + 开机自启

把服务装成用户级服务，登录即启动，手机随时能连。bash scripts/install-service.sh（Linux systemd）。

桌面窗口（无双击安装包）

已经有 Chrome/Edge 的话，npm run app 会直接开一个无地址栏的窗口，效果和装出来的 App 一样，不需要额外打包。

常见问题

手机上打不开？

手机和电脑要在同一个 Wi-Fi。在电脑上设置 JARVIS_HOST=0.0.0.0 并重启，再用电脑的局域网 IP 访问；跨网段请用 Tailscale 之类的私有网络，不要直接暴露到公网。

提示“需要访问令牌”

新设备先配对：电脑上「设置 → 设备 → 生成配对码」，手机上打开 /pair 输入六位数字。配对成功后浏览器会记住凭据 30 天。

Windows / macOS 能跑吗？

能。对话、记忆、提醒、文件、远端模型都可用；屏幕捕获与摄像头目前只支持 Linux。

离线能用吗？

外壳页面可以离线打开，但对话需要模型：本地 Ollama 不需要网络，远端供应商必须联网。
