MODEL PROVIDERS

选一个模型服务，
三步接上。

Jarvis 本身不带模型额度：它连接你选的供应商。国内供应商大多可以直连， 国际供应商需要自备网络。填错也不会把已有配置弄坏——新供应商保存后才生效， 而且可以随时切换或删除。语音识别与合成也有独立的供应商指南， 跳到语音服务 ↓

  1. 1在供应商官网注册，创建 API Key
  2. 2点下面的「用这个供应商」，地址和模型自动填好
  3. 3粘贴 Key，点「添加」——完事

还是拿不定主意？

完全不想花钱

先装 Ollama 在本机跑 3B 模型；电脑配置太低就用 硅基流动 的免费额度，或 Gemini 的免费层（免费层数据会被用于改进产品，隐私内容别走）。

要中文、要稳定、别折腾网络

DeepSeek 或 通义千问。价格低、国内直连、支持支付宝/对公转账。

想要最好的写作和代码

Anthropic Claude 或 OpenAI，需要能访问它们的网络。可以只把它们放在优先级第二位，日常还是走国内。

额度不够想自动切换

配两个以上供应商，在「设置 → 模型」里拖动优先级。额度用完、被限流、Key 失效时，Jarvis 会自动换下一个并在对话里提示。

Jarvis 不会把你的 Key 上传到任何地方：它保存在本机 data/model-config.json（权限 0600）， 既不进备份也不进导出。所有请求都从这台机器直接发往供应商。
